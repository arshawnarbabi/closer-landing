# Closer landing site

Closer is an iMessage negotiation coach for used-car buyers. It's a prototype from the Y Combinator Startup School hackathon in San Francisco, built in one day in July 2026 with a team of four.

An AI model turns each seller message into signals like price, concessions and bluffs, and a Bayesian model estimates the seller's lowest price to suggest a counteroffer.

This repo is only the landing site, which I designed and built by directing Claude Code. My teammates built the backend, and it isn't kept running as a product.

Live site: [test1-pi-flax.vercel.app](https://test1-pi-flax.vercel.app)

Built with Vite, React, TypeScript, Tailwind and Framer Motion.
